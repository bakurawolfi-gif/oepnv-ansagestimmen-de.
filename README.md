# Haltestellenansagestimmen im deutschen ÖPNV

Eine gemeinschaftlich gepflegte Sammlung zu Ansagestimmen in deutschen Bussen und Regionalzügen.

> **Status:** Erste, noch nicht unabhängig verifizierte Sammlung aus Fahrgastbeobachtungen (Stand: 26. Oktober 2026). Die Zuordnungen sind **keine offiziellen Bestätigungen** der Verkehrsunternehmen oder Sprachsoftware-Anbieter.

## Belege ergänzen

Für jede Zuordnung sind möglichst erforderlich: eine öffentlich erreichbare Aufnahme oder offizielle Quelle, Aufnahmedatum, Linie/Fahrzeug, genaue Ansage und ggf. Quelle zur Identität der TTS-Stimme. Eine Einblendung im Video ist ein Hinweis, aber noch keine unabhängige Herstellerbestätigung.

Bitte keine privaten Personen, personenbezogenen Daten oder fremde Audio-/Videoaufnahmen ohne Rechteklärung hochladen. Externe Links zu rechtmäßig veröffentlichten Aufnahmen sind vorzuziehen.
